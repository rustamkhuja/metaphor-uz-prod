# Metaphor: порядок запуска без промежуточных выборов

## Зафиксированное решение

[РЕКОМЕНДАЦИЯ] Metaphor запускается как **AI-помощник для важных разговоров**, а не как генератор литературных поздравлений.

[РЕКОМЕНДАЦИЯ] Каналы первого этапа: мобильный веб, Telegram-бот и Telegram Mini App-compatible web interface. Нативные iOS/Android приложения не разрабатываются до KPI-gate.

Режимы продукта:

1. написать сообщение;
2. ответить на полученное сообщение;
3. улучшить собственный текст;
4. проверить, как текст воспринимается.

Первые 500 завершённых генераций — бесплатная проверка продукта с лимитом 3 AI-вызова на пользователя за скользящие 24 часа. Платёжный контур активируется только после выполнения gate в `docs/10_KPI_AND_GATES.md`.

## Конфигурация запуска

- домен: `app.metaphor.uz`;
- приложение: один Python/FastAPI modular monolith;
- база: PostgreSQL 16;
- reverse proxy/HTTPS: Caddy;
- основной LLM baseline: `grok-4.3`, reasoning `low`;
- модель production: победитель benchmark RU/UZ/EN;
- резервный LLM: подключается после первой недели стабильной эксплуатации;
- хранение: исходный и сгенерированный текст не сохраняются;
- AI-бюджет: 3 USD за скользящие 24 часа;
- Telegram: бот + публичный канал;
- публикация: первые 30 дней только после одобрения оператора;
- контент: один RU и один UZ материал в день;
- B2B: с 31-го дня, виджет для цветочных и подарочных сервисов;
- платежи: Payme Business Merchant API после продуктового gate и договора;
- нативные приложения: запрещены до KPI-gate.

## Порядок передачи

1. владелец выполняет только `docs/19_EXTERNAL_ACTION_TICKETS.md`;
2. сильный технический специалист выполняет `docs/17_HANDOVER.md`;
3. AI/языковой специалист прогоняет `evaluation/test_cases.csv`;
4. юрист заполняет и утверждает `/privacy` и `/terms`;
5. владелец разрешает production deployment;
6. постоянный оператор работает по `docs/08_OPERATOR_RUNBOOK.md`.

## Definition of Done первого запуска

- HTTPS работает на `app.metaphor.uz`;
- RU/UZ/EN интерфейс и генерация проходят benchmark;
- корректный JSON ≥95%;
- Telegram-бот отвечает и требует `/agree`;
- операторская панель показывает расходы и продуктовые метрики;
- контентный цикл создаёт RU/UZ материалы и медиа;
- публикация невозможна без approved state;
- содержание пользовательского текста не хранится;
- backup создаётся и проходит тест восстановления;
- критические ошибки и бюджетный лимит видны оператору;
- юридические страницы содержат реквизиты владельца и заключение юриста; `LEGAL_LAUNCH_APPROVED=true`, версии policy/terms не содержат `draft`;
- 0 открытых P0 и P1 дефектов.
