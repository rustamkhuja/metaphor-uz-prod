# 01. Product Specification

## 1. Назначение

Metaphor помогает человеку подготовить личное сообщение, ответить на входящий текст, улучшить собственную формулировку или проверить восприятие тона на русском, узбекском и английском языках.

## 2. Основные пользователи

1. человек перед важным личным разговором;
2. двуязычный пользователь RU/UZ;
3. сотрудник или руководитель, которому требуется корректное сообщение;
4. покупатель подарка/цветов, которому нужен текст карточки;
5. партнёрская платформа, встраивающая Metaphor в checkout.

## 3. Основные Jobs-to-be-Done

- «Помоги начать разговор после конфликта»;
- «Сделай мой текст мягче, но не слабее»;
- «Ответь на грубое сообщение без скандала»;
- «Переведи на естественный узбекский, сохранив уважение»;
- «Проверь, не звучит ли это обвиняюще»;
- «Создай личное поздравление без шаблона».

## 4. Функциональный объём v0.2.1

### 4.1. Режимы

| Код | Режим | Вход | Выход |
|---|---|---|---|
| `write` | Написать | ситуация, отношения, цель, тон | готовое сообщение |
| `reply` | Ответить | входящий текст + цель ответа | готовый ответ |
| `improve` | Улучшить | собственный черновик | отредактированный вариант |
| `tone_check` | Проверить тон | собственный текст | исправленный вариант + краткая заметка |

### 4.2. Параметры

- язык;
- отношения;
- коммуникативная цель;
- тон;
- длина;
- форма обращения;
- контекст;
- исходный текст.

### 4.3. Действия после генерации

- редактировать результат;
- скопировать;
- поделиться;
- сделать короче;
- сделать теплее;
- сделать увереннее;
- дать положительную/отрицательную оценку.

## 5. Нефункциональные требования

- p95 ответа без web search: до 12 секунд;
- корректный JSON от реального LLM: не менее 95% тестов;
- отсутствие открытого хранения исходного текста по умолчанию;
- ежедневный лимит расходов;
- audit trail административных действий;
- адаптивность от 320 px;
- HTTPS в production;
- деградация на резервного провайдера;
- интерфейс доступен с клавиатуры.

## 6. Не входит в v0.2.1

- психологическая диагностика;
- юридические или медицинские советы;
- автоматическая отправка личного сообщения получателю;
- чтение контактов;
- AI-клавиатура;
- iOS/Android;
- автоматическое сканирование личных переписок;
- обучение собственной модели;
- хранение «памяти отношений» без отдельного согласия.

## 7. Критерий ценности

Пользователь должен получить текст, который он готов отправить после минимальной правки. Формальная красота текста без copy/share считается неуспехом.
