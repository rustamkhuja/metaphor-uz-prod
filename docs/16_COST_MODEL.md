# 16. Модель расходов

## Стартовый лимит

[РЕКОМЕНДАЦИЯ] В первые 30 дней установить `DAILY_AI_BUDGET_USD=3.00`. Максимум около 90 USD в месяц при полном расходовании лимита; фактический расход должен быть ниже.

## Статьи

- VPS;
- LLM продукта;
- LLM контентного конвейера;
- image/video generation при подключении;
- домен и почта;
- платёжные комиссии;
- юридическая проверка;
- стоимость времени оператора.

## Предохранители

- free daily limit;
- один контентный цикл в день;
- web search выключен;
- mock для тестов;
- premium variants только после entitlement;
- отдельный owner approval на повышение бюджета;
- отчёт AI cost за 7 дней в `/operator`.

## Финансовая цель

[ПРЕДПОЛОЖЕНИЕ] При 30–50 млн сумов месячной выручки AI и базовая инфраструктура не должны превышать 10–15% выручки. Основная стоимость будет приходиться на оператора, продажи, партнёрства, юридическую и продуктовую работу.
