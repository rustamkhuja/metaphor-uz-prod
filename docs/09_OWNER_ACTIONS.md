# 09. Действия владельца, которые нельзя выполнить внутри пакета

Этот файл является краткой версией. Исполнять tickets из `docs/19_EXTERNAL_ACTION_TICKETS.md`.

## До технического запуска

- [ ] Создать xAI API key и пополнить баланс на 20 USD.
- [ ] Создать через BotFather бот `Metaphor | Важные слова`.
- [ ] Создать публичный Telegram-канал `Metaphor — важные слова`.
- [ ] Назначить бота администратором канала с правом публикации.
- [ ] Предоставить VPS: 2 vCPU, 4 GB RAM, 40 GB SSD, Ubuntu LTS, публичный IPv4, Docker/Compose.
- [ ] Создать DNS A-запись `app.metaphor.uz` на IPv4 VPS.
- [ ] Передать секреты назначенному DevOps через закрытый канал.
- [ ] После приёмки дать письменное разрешение на production deployment.

## До публичного запуска

- [ ] Указать юридического владельца, адрес и контакт.
- [ ] Передать privacy/terms и data-flow map юристу.
- [ ] Получить письменное заключение по персональным данным, иностранному LLM, регистрации базы и публичной оферте.
- [ ] Подтвердить запрет хранения пользовательского содержания на первом этапе.
- [ ] Подтвердить верхний AI-бюджет 90 USD в месяц.
- [ ] Проверить право использования домена и названия Metaphor.

## После продуктового gate

- [ ] Подтвердить цену 19 900 сумов за «Важное сообщение».
- [ ] Подать заявку в Payme Business на Merchant API.
- [ ] Подписать договор, утвердить чек/возврат/бухгалтерский порядок.
- [ ] Разрешить техническую интеграцию платежей.
- [ ] Подписать первый B2B-пилот.

## Социальные платформы после Telegram

- [ ] Создать/подтвердить professional Instagram account и Meta developer app.
- [ ] Создать TikTok developer app и пройти Content Posting API review.
- [ ] Создать YouTube channel и OAuth credentials.
- [ ] Отдельно разрешить автопубликацию после 30 дней ручной приёмки.

## На первом этапе не требуется

- новый домен;
- iOS/Android developer accounts;
- собственный GPU;
- отдельная SMM-команда;
- обучение собственной LLM;
- крупная рекламная закупка.
