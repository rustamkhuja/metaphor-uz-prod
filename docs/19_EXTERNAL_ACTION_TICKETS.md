# 19. Внешние действия владельца и разовой команды

## Назначение

Внутри пакета выполнены архитектура, код, тесты, инструкции и локальная приёмка. Ниже перечислены только действия, которые требуют внешнего аккаунта, оплаты, юридического решения, доступа к DNS/VPS или разрешения владельца.

## Ticket EXT-01 — xAI API

**Исполнитель:** владелец аккаунта/финансово уполномоченное лицо.  
**Действие:**

1. создать отдельный team/project `Metaphor Production` в xAI Console;
2. выпустить production API key;
3. пополнить баланс на 20 USD;
4. не отправлять ключ в мессенджер или общий документ;
5. передать ключ DevOps через password manager/secret vault;
6. установить hard operational limit: `DAILY_AI_BUDGET_USD=3.00`.

**Результат:** DevOps получает секрет и выполняет реальный benchmark/API smoke test.

## Ticket EXT-02 — Telegram

**Исполнитель:** владелец Telegram-аккаунта.

1. через BotFather создать `Metaphor | Важные слова`;
2. username назначить в доступном варианте, содержащем `metaphor`;
3. создать публичный канал `Metaphor — важные слова`;
4. назначить бота администратором с правом публикации;
5. передать DevOps bot token и channel id через secret vault;
6. передать личный operator chat id для аварийных уведомлений.

**Результат:** DevOps устанавливает webhook и выполняет `/start` → `/agree` → generation → `/delete`.

## Ticket EXT-03 — VPS и DNS

**Исполнитель:** владелец инфраструктуры/DevOps.

1. предоставить VPS: Ubuntu LTS, 2 vCPU, 4 GB RAM, 40 GB SSD, публичный IPv4;
2. установить Docker Engine и Docker Compose plugin;
3. разрешить входящие TCP 80/443; SSH ограничить доверенными адресами/VPN;
4. создать DNS A-запись `app.metaphor.uz` на IPv4 VPS;
5. передать DevOps SSH-доступ;
6. резервное копирование хранить в Docker volume на старте, затем подключить внешнее encrypted storage после первой недели.

**Результат:** `https://app.metaphor.uz/api/v1/health` возвращает status `ok`.

## Ticket EXT-04 — реквизиты и юридическое заключение

**Исполнитель:** владелец + юрист.

1. определить юридического владельца сервиса;
2. предоставить полное наименование, адрес, email и телефон;
3. проверить data-flow: пользователь → Metaphor VPS → xAI → ответ;
4. письменно определить применимость регистрации базы персональных данных;
5. письменно оценить передачу текста иностранному AI-провайдеру;
6. утвердить privacy/terms;
7. сохранить запрет хранения пользовательского содержания на первом этапе;
8. определить порядок обработки запросов на удаление/доступ;
9. проверить право использования названия и домена Metaphor;
10. после письменного заключения установить final `PRIVACY_POLICY_VERSION`, `TERMS_VERSION` и `LEGAL_LAUNCH_APPROVED=true`.

**Результат:** placeholders в `/privacy` и `/terms` заменены; юридический запуск разрешён письменно.

## Ticket EXT-05 — production deployment

**Исполнитель:** владелец.

После получения технического, AI/language, security/privacy и legal acceptance:

1. проверить acceptance checklist;
2. дать письменное разрешение `APPROVED FOR PRODUCTION DEPLOYMENT`;
3. разрешить публикацию сайта и Telegram-бота;
4. первые 30 дней не разрешать автоматическую публикацию контента без human approval.

**Результат:** DevOps выполняет production deployment и фиксирует release tag `v0.2.1`.

## Ticket EXT-06 — тестовая аудитория

**Исполнитель:** владелец/оператор.

1. предоставить закрытой бете 50–100 реальных пользователей;
2. не подсказывать им, какой результат считается правильным;
3. не включать оплату;
4. собрать минимум 500 завершённых генераций;
5. выполнить gate по `docs/10_KPI_AND_GATES.md`.

**Результат:** решение `STOP / ITERATE / MONETIZE` основано на данных.

## Ticket EXT-07 — платежи после gate

**Исполнитель:** владелец + бухгалтер/юрист + backend specialist.

1. подтвердить цену 19 900 сумов;
2. подать заявку в Payme Business на Merchant API;
3. подписать договор;
4. утвердить публичную оферту, возврат и фискализацию;
5. получить merchant credentials;
6. только после этого поручить backend integration;
7. провести sandbox tests и reconciliation test;
8. включить payment feature flag.

**Результат:** платёж не считается успешным по redirect клиента; истиной является подтверждённая серверная транзакция провайдера.

## Ticket EXT-08 — Instagram/TikTok/YouTube после Telegram

**Исполнитель:** владелец аккаунтов + growth operator.

1. создать professional Instagram account и Meta developer app;
2. получить publishing permissions;
3. создать TikTok developer app и пройти Content Posting review;
4. создать YouTube channel, Google Cloud project и OAuth credentials;
5. передать credentials через secret vault;
6. 30 дней публиковать только после human approval;
7. разрешить controlled auto-publish только после 50 последовательных корректных публикаций и отсутствия policy strikes.

**Результат:** официальный API, без browser automation, ферм аккаунтов и обхода ограничений.

## Ticket EXT-09 — первый B2B-пилот

**Исполнитель:** владелец/оператор.

1. выбрать один цветочный или подарочный сервис из существующих контактов;
2. подписать 30-дневный пилот;
3. установить виджет с уникальным `partner_code`;
4. определить baseline checkout completion;
5. сравнить использование и завершение заказа;
6. после пилота подписать платный договор либо закрыть канал.

**Результат:** измеримый B2B-кейс, а не бесплатная бессрочная интеграция.
