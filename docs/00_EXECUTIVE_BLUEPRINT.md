# 00. Исполнительная модель Metaphor

## Решение

[РЕКОМЕНДАЦИЯ] Metaphor должен стать компактным AI-first бизнесом с одним постоянным product/growth operator и периодическим экспертным контролем. Цель системы — не максимальная автономность любой ценой, а **минимальная стоимость одного доказанного результата пользователя**.

## Продуктовая формула

> Пользователь описывает ситуацию и цель → Metaphor предлагает уместный текст → пользователь редактирует, копирует или отправляет → система измеряет результат → следующие изменения принимаются по данным.

## Северная звезда

`send_or_copy_events / completed_generations`

Просмотры, число публикаций и количество сгенерированных текстов не являются главными KPI.

## Организационная модель

| Контур | Выполняет AI/код | Выполняет человек |
|---|---|---|
| Генерация сообщений | Да | Проверяет жалобы и качество выборки |
| Локализация RU/UZ/EN | Да | Еженедельная выборочная редактура |
| Контент-план | Да | Утверждает одну гипотезу в неделю |
| Посты и карточки | Да | Первые 30 дней одобряет публикацию |
| Telegram-публикация | Да после gate | Включает автопубликацию |
| Поддержка первого уровня | Да | Платежи, удаление данных, репутационные случаи |
| Аналитика | Да | Принимает stop/continue/scale |
| B2B-лидогенерация | Частично | Переговоры, договор, цена |
| Финансовые лимиты | Код | Утверждает бюджет и тарифы |
| Юридическая ответственность | Нет | Владелец и юрист |

## Финансовая логика

[ПРЕДПОЛОЖЕНИЕ] В первые 90 дней основной результат — доказательство спроса, а не максимизация выручки. После подтверждения copy/share и возвратов включаются:

- разовая покупка «Важное сообщение»;
- пакет кредитов;
- B2B-виджет;
- партнёрские продажи открыток, цветов и подарков.

## Жёсткие ограничения

- не создавать десятки неконтролируемых агентов;
- не публиковать автоматически юридические, медицинские, политические или кризисные материалы;
- не оптимизировать контент по охвату без привязки к использованию продукта;
- не хранить личные сообщения без необходимости;
- не разрабатывать нативные приложения до KPI-gate;
- не обучать собственную модель на первом этапе;
- не масштабировать рекламу до доказанной конверсии.
