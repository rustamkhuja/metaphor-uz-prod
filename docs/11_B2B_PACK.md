# 11. B2B-пакет

## Продукт

**Metaphor Widget** — встроенный помощник, который создаёт персональный текст для открытки непосредственно на странице заказа цветов, подарка, торта или приглашения.

## Ценность партнёру

- меньше отказов на этапе заполнения карточки;
- более персонализированный заказ;
- дополнительная премиальная услуга;
- RU/UZ/EN без ручного копирайтинга;
- white-label;
- аналитика использования.

## Пилот

- 30 дней;
- один checkout flow;
- до согласованного лимита генераций;
- совместная аналитика;
- без доступа Metaphor к платёжным данным;
- отключение одним feature flag.

## Техническая интеграция

Партнёр встраивает iframe/widget. Metaphor получает только контекст для карточки и возвращает текст. Имена и персональные данные должны быть минимизированы.
