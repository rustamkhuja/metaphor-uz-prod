# 05. Growth Engine

## Цель

Привлекать пользователей копеечными каналами и превращать каждое полезное сообщение в следующий контакт с продуктом.

## 1. Telegram-loop

1. пользователь создаёт сообщение;
2. копирует или оформляет карточку;
3. карточка содержит ненавязчивое `Создано в Metaphor`;
4. получатель открывает ссылку;
5. новый пользователь получает одну premium-генерацию;
6. referral учитывается в аналитике.

## 2. Контентная машина

Ежедневно:

- один RU пост;
- один UZ пост;
- одна карточка для каждого языка;
- один CTA, ведущий в конкретный режим;
- никаких общих постов «про возможности AI».

Рабочая формула:

> узнаваемая плохая фраза → почему она не работает → более точный вариант → открыть соответствующий режим Metaphor.

## 3. SEO

Страницы создаются вручную из проверенной библиотеки сценариев, затем AI поддерживает обновление. Начальные кластеры:

- извинение;
- поддержка;
- границы;
- ответ на грубость;
- благодарность;
- поздравления;
- сообщения старшим;
- RU–UZ адаптация;
- деловая переписка.

Запрещено массово генерировать тысячи однотипных страниц.

## 4. Эксперименты

Только один growth experiment в неделю. Для каждого обязательны:

- гипотеза;
- метрика;
- аудитория;
- минимальный объём;
- stop-condition;
- решение keep/kill/iterate.

## 5. Контентные KPI

- переходы в конкретный режим;
- completed generation;
- copy/share;
- платная покупка;
- стоимость AI-производства;
- негативная обратная связь.

Просмотры и лайки являются диагностикой, но не конечной целью.

## 6. B2B-growth

Приоритетный сценарий — виджет в checkout цветочного или подарочного сервиса. Партнёр получает более персонализированную карточку и потенциально более завершённый заказ; Metaphor получает дистрибуцию и плату за использование/лицензию.
