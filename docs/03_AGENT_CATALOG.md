# 03. Каталог агентов и автоматизаций

## Принцип

Агент не является «виртуальным сотрудником с полной свободой». Это ограниченная функция с конкретным входом, выходом, бюджетом и условием передачи человеку.

| Агент | Запуск | Вход | Выход | Human gate |
|---|---|---|---|---|
| Trend Agent | ежедневно | дата, регион | проверенные поводы и источники | если нет источника — сигнал не используется |
| Content Planner | ежедневно | календарь, тренды, метрики | тема, формат, CTA | нет |
| Content Creator | ежедневно | утверждённая тема | RU/UZ посты и card text | через QA |
| Quality Agent | после создания | текст | score, риск, исправленная версия | score <85 или риск ≠ low |
| Publisher | после approval | approved content | message ID | первые 30 дней всегда |
| Growth Analyst | еженедельно | first-party metrics | одна гипотеза и stop-condition | всегда |
| Support Triage | по обращению | вопрос пользователя | ответ или escalation | платежи, удаление, жалобы |
| Budget Guard | каждый запрос | расход за 24 часа | allow/deny | изменение лимита |
| Retention Cleaner | ежедневно | записи старше срока | удаление raw payload | отчёт об ошибке |

## Автономность по этапам

### Дни 1–30

- контент создаётся автоматически;
- любой пост одобряет оператор;
- web search выключен;
- ответы поддержки только по готовой базе;
- B2B-письма не отправляются автоматически.

### Дни 31–60

- low-risk Telegram-посты можно автопубликовать после 50 подряд принятых материалов;
- негативные комментарии и жалобы передаются человеку;
- недельный growth experiment утверждает оператор.

### После 60 дней

- автопубликация сохраняется только при доле отклонённых материалов <5%;
- любые изменения цены, лимита, платежей и privacy остаются за владельцем;
- Instagram/TikTok/YouTube включаются только через официальные API и отдельные credentials.

## Запрещённые полномочия агентов

- тратить деньги сверх лимита;
- подписывать договор;
- менять цену;
- удалять данные вне retention policy;
- публиковать политический контент;
- отвечать на угрозы, self-harm или публичный кризис без человека;
- создавать фиктивные отзывы или имитировать пользователей;
- массово регистрировать аккаунты;
- публиковать непроверенные факты и цитаты.
