# Security policy

Не публикуйте уязвимости, API keys, пользовательские тексты или production-конфигурацию в открытых issues.

До указания официального security contact сообщение направляется непосредственно юридическому владельцу сервиса через закрытый канал. Перед публичным запуском этот файл должен содержать:

- security email;
- supported versions;
- expected response time;
- порядок шифрованной передачи evidence;
- правила coordinated disclosure.

Production запрещён, пока legal/security placeholders не закрыты по `docs/19_EXTERNAL_ACTION_TICKETS.md`.
